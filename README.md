# ARTIFURA — Precision Technology Advisory & High-Performance Engineering

> Official web portfolio for **[artifura.in](https://artifura.in)**.

ARTIFURA is a precision technology advisory and engineering firm building digital products, resilient software, and intelligent agentic systems for enterprises ready to scale.

---

## ⚡ Tech Stack

- **Framework**: [React 19](https://react.dev) + [Vite](https://vitejs.dev) + [TypeScript](https://www.typescriptlang.org)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com)
- **Animations**: [Motion](https://motion.dev) + [Lenis Smooth Scroll](https://lenis.darkroom.engineering)
- **Icons**: [Lucide React](https://lucide.dev)
- **Deployment**: GitHub Pages (`gh-pages`) with Custom Domain (`artifura.in`)

---

## 🚀 Development & Deployment

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Deploy to GitHub Pages (`artifura.in`)
```bash
npm run deploy
```
This automatically builds the project into `dist/` with the custom domain `CNAME` and pushes the production bundle to the `gh-pages` branch.
